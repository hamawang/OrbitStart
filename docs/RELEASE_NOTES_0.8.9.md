# OrbitStart 0.8.9 更新公告

发布日期: 2026-08-05

## ## 本次更新

- **解除默认标签不可删除限制**：取消了对系统默认标签/分组（如应用、网址、脚本、工具等）的强制保护逻辑。现在所有标签均支持自由删除、重命名与自定义排布，提供更高的工作台个性化自由度。
- **关联资源自动重定向**：删除任意标签时，若被删除标签下包含绑定的资源，系统将自动把关联资源安全平滑迁移至已有标签下，确保数据不会意外挂空或丢失。

## ## 兼容性与数据

- 本版本完全兼容现有的 SQLite 数据库与配置文件，覆盖升级不影响资源、分组、主题及插件设置。

## ## 更新方式

- 已安装 0.8.2 或更高版本的用户，可在“设置 -> 关于 -> 检查更新”中升级。
