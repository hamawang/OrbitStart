# OrbitStart 0.8.4 更新公告

发布日期：2026-07-28

OrbitStart 0.8.4 集中完成本轮可维护性、资源安全和发布可靠性优化。主界面使用方式保持不变，重点减少悬浮窗口的加载范围、避免不必要的全量状态刷新，并补齐资源路径修复与发布回归保护。

## 本次更新

- 悬浮球和悬浮菜单改为独立窗口入口，不再加载完整主应用；启动时只加载窗口所需的界面、外观设置和错误上报代码。
- 插件启用状态与安全模式改为定向状态更新，不再为这些设置重新拉取完整资源目录快照。
- 工作区编辑器继续按列表、图模型、模态框和右键菜单拆分，降低后续维护风险；补充工作区编辑、资源选择、图/列表切换和右键编辑的回归测试。
- 数据设置页新增“检查并预览路径修复”：仅对用户确认的缺失绝对路径生成有边界的前缀替换预览；保存前创建目录备份，绝不移动、删除或覆盖磁盘文件。
- 插件能力、插件 manifest 和安全文档由同一契约检查器校验；核心快捷方式权限进一步收紧为最小 `launcher:item`。
- 改进 Windows E2E 进程回收。测试断言通过后会清理自身启动的 Vite 进程并确认端口可复用，避免 CI 将成功测试误报为 webServer 超时。
- 新增性能采样对比工具，用于在同一设备、同一窗口场景下比较优化前后的内存与 CPU 数据。
- 在“关于”设置页新增“检查更新”入口：可手动检查 GitHub Release，发现新版本后显示更新说明、下载进度，并在安装完成后自动重启。

## 用户影响

- 不迁移、不删除现有资源、分组、主题、插件或设置数据。
- 路径修复默认只提供预览；相对路径、权限错误、网络不可用和仍可用的路径不会被自动改写。
- 悬浮球、资源编辑、工作区和插件设置的操作入口保持原有行为。

## 更新方式

- 已安装 0.8.2 或 0.8.3 的用户：在 GitHub Release 上传本版本安装包、同名 `.sig` 和 `latest.json` 后，可通过应用内更新检查获取 0.8.4。
- 0.8.1 及更早版本仍信任旧 updater 公钥，需要先手动安装 0.8.2 或更高版本一次，之后才能进入当前自动更新链路。
- 安装或覆盖安装前，请先完全退出正在运行的 OrbitStart；现有数据将按当前安装或便携模式保留。

## 发布校验

- 前端生产构建、插件安全与性能工具校验、版本一致性校验均已通过。
- Playwright 基础/资源/工作区回归共 21 项通过，主题回归 6 项通过；Rust 单元测试 30 项通过。
- 本 Release 将附带 NSIS 安装包、同名 updater `.sig` 与 `latest.json`；`.sig` 用于 Tauri 自动更新校验，不等同于 Windows Authenticode 代码签名。
