# OrbitStart 0.8.8 更新公告

发布日期：2026-07-30

## 本次更新

- **修复 ESC 键系统级劫持问题**：移除了最小化快捷键的 Windows 系统全局钩子注册，解决 OrbitStart 在后台运行/挂机时导致 Chrome、VS Code、游戏等其他应用 `ESC` 键失效的 Bug。
- **窗口获焦级 ESC 最小化逻辑**：优化为仅在 OrbitStart 处于最上层获焦状态时，按 `ESC` 键才会响应并平滑隐藏/最小化主窗口（收起至托盘或悬浮球）。
- **后台零拦截与零干扰**：后台挂机时彻底取消底层键盘 Hook，零占用、零劫持系统全局按键。
- **自定义与清除设置**：可在“设置 → 基础设置”中修改或禁用该窗口最小化快捷键。

## 兼容性与数据

- 本版本完全兼容现有的 SQLite 数据库与配置文件，覆盖升级不影响资源、分组、主题及插件设置。

## 更新方式

- 已安装 0.8.2 或更高版本的用户，可在“设置 → 关于 → 检查更新”中升级。
- 请在 GitHub Release 中同时上传安装包、同名 `.sig` 签名文件和 `latest.json`。
