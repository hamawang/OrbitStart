# OrbitStart 0.8.2 更新公告

发布日期：2026-07-26

OrbitStart 0.8.2 是一次围绕稳定性、启动效率、数据安全和发布链路完成的维护版本。

## 本次更新

- 优化原生调用失败时的处理：桌面端会返回明确错误并记录日志；仅浏览器预览模式保留本地存储 fallback，避免桌面端悄然写入不一致的数据。
- 优化数据库生命周期：启动阶段完成初始化与默认数据准备，常规命令保持短连接；加入带事务和迁移前备份的数据库迁移机制。
- 优化界面加载：工作区、悬浮球、行程面板和引导页面改为按需加载；悬浮球窗口只读取所需的外观设置。
- 减少不必要的数据传输：资源变更改为定向事件和按 ID 更新，常用设置命令不再返回完整资源快照。
- 加强安全边界：URL 可访问性检查不再拼接 PowerShell 命令；打开 Obsidian 笔记前会校验路径始终位于 vault 内。
- 增加发布防回归检查：`npm run version:check` 会检查前端、lockfile、Cargo 和 Tauri 配置版本；`npm run release:verify` 会检查更新清单、签名备注和安装包名的一致性。

## 更新方式

由于历史 updater 私钥已经丢失，0.8.2 使用了新的签名密钥。已安装 0.8.1 或更早版本的用户无法通过旧版自动更新直接升级，需先手动安装 `OrbitStart_0.8.2_x64-setup.exe` 一次。

从 0.8.2 开始，后续版本将继续沿用新的签名链路，自动更新可以恢复正常使用。

安装或升级前，如有重要本地数据，建议先自行备份；不要为了升级而手动删除应用数据目录。
