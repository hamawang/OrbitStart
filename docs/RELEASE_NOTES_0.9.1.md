# OrbitStart 0.9.1 更新公告

发布日期: 2026-08-26

## 本次更新

- **标签管理修复**：自定义标签现在可以从右键菜单直接重命名，并同步更新本地数据。
- **资源录入改进**：支持把文件直接拖入资源编辑器，自动填充目标路径、标题和说明；桌面文件选择器也扩展了常用文档、压缩包、脚本与快捷方式类型。
- **路径信息更易查看**：资源名称或路径被截断时，可通过悬浮提示查看完整目标信息。
- **界面错位修复**：搜索框只保留一层聚焦反馈，标签和资源图标不再出现图片高光与组件边框错位，空资源列表在多列布局中保持完整居中。

## 兼容性与数据

- 本版本兼容现有 SQLite 数据库、资源、分组、主题和插件配置，可直接覆盖安装。
- 本版本不改变插件 manifest、资源数据或设置文件格式。

## 更新方式

- 已安装支持自动更新版本的用户，可在“设置 → 关于 → 检查更新”中升级。
- 也可以下载 `OrbitStart_0.9.1_x64-setup.exe` 直接覆盖安装。
