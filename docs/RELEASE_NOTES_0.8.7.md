# OrbitStart 0.8.7 更新公告

发布日期：2026-07-30

## 本次更新

- **全局最小化快捷键支持**：新增全局最小化/隐藏快捷键功能，默认绑定 `Escape` 键。
- **独立热键设置与持久化**：可在“设置 → 基础设置”中自由绑定、修改或禁用全局最小化热键，设置会自动在本地 SQLite 数据库中持久化。
- **全局冲突保护与热键切换**：支持注册与解绑，如需切换为其他组合键（例如 `Alt+Esc` 或 `Ctrl+Shift+M`）或禁用该功能，直接在设置页中操作即可。
- **唤出与最小化双热键矩阵**：主唤出热键（默认 `Ctrl+Alt+Space`）与最小化热键协同工作，提升全局键盘导向操作体验。

## 兼容性与数据

- 本版本继续兼容现有的 SQLite 数据库与配置文件，升级不会影响现有资源、分组、工作区、主题、插件及热键配置。

## 更新方式

- 请在 GitHub Release 中同时上传安装包、同名 `.sig` 签名文件和 `latest.json`。
- 已启用应用内自动更新的用户，可在“设置 → 关于 → 检查更新”中升级。
- 安装或覆盖安装前，请确保已完全退出正在运行的 OrbitStart 进程。
