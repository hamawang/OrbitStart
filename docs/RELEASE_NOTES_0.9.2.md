# OrbitStart 0.9.2 更新公告

发布日期: 2026-08-29

## 本次更新

- **默认标签删除持久化**：修复了基础默认标签（应用、脚本、插件等）在删除后重启软件时又会自动重新创建的问题。现在所有标签删除操作在软件重启后均会持久生效。
- **数据初始化机制优化**：改进了数据库启动引导流程，避免重复触发默认分组和示例资源的注入。

## 兼容性与数据

- 本版本兼容现有 SQLite 数据库、资源、分组、主题和插件配置，可直接覆盖安装。
- 历史数据不受影响，已删除的默认标签不会被重新创建。

## 更新方式

- 已安装支持自动更新版本的用户，可在“设置 → 关于 → 检查更新”中升级。
- 也可以下载 `OrbitStart_0.9.2_x64-setup.exe` 直接覆盖安装。
