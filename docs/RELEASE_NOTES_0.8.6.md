# OrbitStart 0.8.6 更新公告

发布日期：2026-07-29

## 本次更新

- 建立统一的 UI 动画规范，提供完整、标准、精简和关闭四档动画等级。
- 支持跟随 Windows“减少动态效果”设置，并在应用首帧加载前应用动画策略，减少界面闪动。
- 优化按钮、菜单、弹窗、列表、子目录、状态提示和页面切换的反馈与过渡。
- 改进资源拖拽、批量选择、删除状态和错误提示，减少布局跳变与动画冲突。
- 优化首次引导、工作区启动流程和悬浮球交互；悬浮球继续使用轻量 CSS 动画，避免加载完整动画运行时。
- 动画能力按需加载，并在大列表、后台窗口及低动态等级下主动降级。
- 修复资源分组标签选中态重复套框、分组快捷键角标错位，以及资源卡片快捷键被拉伸成横栏的问题。
- 加强工作区多窗口启动的所有权、租约、取消和恢复机制，避免重复执行及旧窗口覆盖新状态。
- 插件命令与搜索操作支持可配置长任务超时，修复长时间工作区启动被固定超时中断的问题。

## 兼容性与数据

- 本版本继续使用现有本地数据库与配置目录，不会主动迁移或删除用户资源、分组、主题、插件和设置。
- 更新后如不希望显示动画，可在外观设置中选择“关闭”，或启用 Windows 的“减少动态效果”。

## 更新方式

- 请在 GitHub Release 中同时上传安装包、同名 `.sig` 文件和 `latest.json`。
- 已安装支持自动更新版本的用户，可在“设置 → 关于 → 检查更新”中升级。
- 安装或覆盖安装前，请先完全退出正在运行的 OrbitStart。
