# OrbitStart 0.8.5 更新公告

发布日期：2026-07-29

## 本次更新

- 新增资源卡片的独立全局快捷键：右键点击资源后，可直接绑定、修改或删除快捷键。
- 资源编辑页面新增“资源全局快捷键”区域，可查看当前组合、录入新组合或解除绑定。
- 已绑定快捷键的资源卡片会显示对应组合的主题化角标，便于快速识别。
- 录入完成后，按下快捷键会直接启动对应资源；支持 `Ctrl`、`Alt`、`Shift`、`Win` 与任意单键的组合。
- 快捷键绑定会随应用持久化保存，并在下次启动时自动恢复注册。
- 删除资源时会自动解除并清理其快捷键绑定，避免留下失效的全局快捷键。

## 使用说明

该功能使用现有的“快捷键绑定”插件。请在“设置 → 插件管理”中保持该插件启用；若插件被停用，资源的快捷键入口会暂时隐藏，已保存的绑定不会被删除。

## 更新方式

- 已使用 0.8.2 或更高版本的用户：在 GitHub Release 上传本版本安装包、同名 `.sig` 文件和 `latest.json` 后，可在“设置 → 关于 → 检查更新”中更新。
- 安装或覆盖安装前，请先完全退出正在运行的 OrbitStart。现有资源、分组、主题、插件和设置数据不会被迁移或删除。
